# V35 Mobile First Completo

## Objetivo

Melhorar a experiência de preenchimento no celular sem transformar o formulário em 191 páginas.

## Incluído

- Desktop preservado.
- Celular com layout mais confortável.
- Campos maiores.
- Cards individuais para campos.
- Navegação de seções horizontal e sticky.
- Botões Voltar/Próxima fixos no rodapé em celular.
- Cabeçalho do formulário mais compacto no celular.
- Melhor usabilidade para iPhone/Android.
- Compatibilidade com os emails Orlando funcionando em todos os modelos.

## Integração WhatsApp — avaliação

### Fácil / recomendada agora
Criar botão no admin para abrir WhatsApp Web/App com mensagem pronta:
`https://wa.me/55NUMERO?text=MENSAGEM`

Vantagens:
- rápido;
- barato;
- não exige API oficial;
- você confere antes de enviar;
- funciona bem com WhatsApp Business.

Limitação:
- o envio final ainda depende de você clicar/enviar no WhatsApp.

### Complexo / envio automático real
Usar WhatsApp Business Cloud API da Meta.

Exige:
- conta Meta Business;
- número conectado à API;
- templates aprovados;
- webhook;
- controle de opt-in;
- custo por conversa;
- implementação bem mais delicada.

Recomendação: começar com botão WhatsApp com mensagem pronta.
