# V115A — Correção de dados de passaporte

## Correção

A V115 ajustou o card principal de passaporte, mas a tela de relatório/dados ainda exibia colunas de visto.

Nesta V115A:

- clientes de Passaporte não exibem alertas de CASV/entrevista/videochamada no resumo;
- o relatório mostra:
  - CASV / Cidade PF;
  - Entrevista / Agendamento passaporte;
  - Consulado / Local PF;
- para Passaporte, essas colunas recebem:
  - cidade PF;
  - data/hora do agendamento PF;
  - local PF.

## Mantém tudo da V115

Sem SQL novo.
