# V82 — Campos bloqueados em cinza

## Alteração

Todos os campos que forem desabilitados automaticamente por regras condicionais passam a ficar visualmente cinza.

## Inclui

- fundo cinza nos campos bloqueados;
- texto suavizado;
- cursor de bloqueio;
- aviso: "Campo desabilitado automaticamente conforme resposta anterior."

## Exemplo atual

Se a pergunta 1.6 for respondida como "Não", a pergunta 1.7 fica bloqueada e visualmente cinza.

## SQL

Não precisa executar SQL novo.
