# V77 — Editor de email em texto simples

## Correção

O editor de email da V76 mostrava o HTML bruto, o que não era adequado para uso operacional.

Agora:

- o campo principal mostra apenas texto simples;
- você pode apagar, acrescentar e personalizar sem ver código;
- o botão `Gerar pré-visualização` aplica o layout visual do email;
- o envio continua sendo feito pelo próprio sistema/Brevo.

## Também corrigido

A Agenda pesquisas também usa o mesmo modelo:
- texto simples;
- pré-visualização;
- envio pelo sistema.

## SQL

Não precisa executar SQL novo.
