# V91 — Newsletter com destinatário correto em emails duplicados

## Correção

Quando várias pessoas usam o mesmo email, a newsletter continua enviando apenas 1 email.

Agora o nome usado como destinatário segue esta regra:

1. Usa o nome do líder do grupo/processo, quando houver líder marcado.
2. Se não houver líder, usa o nome da pessoa mais velha entre os clientes que possuem aquele mesmo email.
3. Se ainda houver empate, usa visto aprovado, processo concluído e cadastro mais antigo como critérios finais.

## SQL

Não precisa executar SQL novo se o SQL da V89 já foi executado.
