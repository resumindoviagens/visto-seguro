# V26 — Correção de build/npm na Vercel

## O que foi corrigido

- Removido uso de `latest` no package.json.
- Dependências travadas nas versões já usadas pelo package-lock.
- Adicionado Node 20.x em `engines`.
- Adicionado `.npmrc` para reduzir checagens do npm.
- Adicionado `vercel.json` com:
  - `installCommand`: `npm ci --no-audit --no-fund`
  - `buildCommand`: `npm run build`

## Por que isso foi feito

O erro:

`npm error Exit handler never called!`

ocorre durante a instalação, antes do build do Next.js. Dependências como `latest` deixam a instalação menos previsível. A v26 deixa o ambiente mais estável.

## Supabase

Não precisa rodar SQL novo.

## Domínio próprio

Pode continuar configurando normalmente. Esta correção não remove o domínio `vercel.app` nem interfere no domínio próprio.
