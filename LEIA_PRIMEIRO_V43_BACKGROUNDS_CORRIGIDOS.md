# V43 — Correção dos fundos das postagens

A versão anterior gerou fundos escuros/artificiais demais.

Esta versão substitui os fundos por 10 imagens limpas, abstratas e mais estáveis para renderização:
`public/feedback-backgrounds/feedback-bg-01.jpg` até `feedback-bg-10.jpg`

Também mantém:
- apenas o botão `Feedbacks / Avaliações`;
- escolha automática de fundo;
- imagem de cabeçalho dos emails sem alteração.

Não há SQL novo obrigatório nesta versão.
